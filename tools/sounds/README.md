# 効果音

`python3 make_sounds.py` で `Resources/Sounds/` に効果音を合成します（標準ライブラリのみ）。

録音した素材に差し替えるときは、同じファイル名（拡張子は .wav / .caf / .m4a / .mp3 のどれでも可）で `Resources/Sounds/` に置いてください。同じ名前で拡張子が違うファイルを残さないようにします。

| ファイル名 | いつ鳴るか |
|---|---|
| `wind_tick` | 巻き上げのカチカチ |
| `wind_complete` | 巻き切ったとき |
| `flash_switch` | フラッシュのスイッチ |
| `envelope_flap` | 封筒のふたが開いたとき |
| `pack_tear` | 袋を破り切ったとき |
