# 6台の色味のたたき台

実行には `pip install numpy scipy pillow` が必要です。どこから実行しても、LUTは `Resources/LUTs/` に書き出されます。

使い捨てカメラアプリの6台（SUNDAY 400 / NOIR 1600 / SPLASH 200 / ALBUM 100 / NITE 800 / RAINY 400）の色味の出発点です。ここから実際の写真で調整していく前提の、たたき台です。

## 入っているもの

| ファイル | 中身 |
|---|---|
| `../../Resources/LUTs/*.cube` | 6台分の3D LUT（33×33×33、sRGBガンマ空間で入出力） |
| `make_luts.py` | LUTを作るスクリプト。数値を変えて実行し直せば作り直せる |
| `preview.py` | LUTをテスト画像に当てて比較シートを作るスクリプト |
| `looks_preview.png` | 比較シート（元画像＋6台） |
| `../../docs/reference/FilmLook.swift` | Core Imageで1枚を加工する処理のたたき台（切り抜き〜日付まで） |

## 加工の順番

1. 3:2に切り抜き
2. 1536×1024に縮小（当時の写真屋さんのCD書き込みくらいの大きさ）
3. LUTで色味
4. 粒子
5. 周辺減光
6. 光漏れ（設定でONのときだけ。初期値OFF）
7. 日付（設定でONのときだけ。初期値ON）

日付と光漏れは**撮った瞬間の設定**で焼き込みます。撮影直後に加工してアプリ内に保存し、封筒を開けたときに写真アプリへ保存します。

色味以外（粒子・周辺減光・光漏れ・日付）をLUTに入れていないのは、LUTは「色を色に置き換える」ことしかできず、場所によって変わる効果（端が暗い、粒子がざらつく）は表現できないからです。

## 6台の設定値

| カメラ | 色味のねらい | 粒子 | 粒子の大きさ | 周辺減光 |
|---|---|---|---|---|
| SUNDAY 400（無料） | 90年代の写真屋プリント。暖色、赤と黄がよく出る、適度なコントラスト、黒が少し浮く | 0.030 | 1.4 | 0.28 |
| NOIR 1600 | 70年代の高感度モノクロ。赤フィルター気味の白黒変換、強いコントラスト、わずかに温黒調 | 0.060 | 2.0 | 0.38 |
| SPLASH 200 | 90年代の夏。露出オーバー気味、シアン寄り、白はやわらかく飛ぶ、コントラスト低め | 0.020 | 1.2 | 0.18 |
| ALBUM 100 | 80年代の家族アルバム。色あせ、黒が浮く、緑が深い、ハイライトが黄ばむ | 0.016 | 1.0 | 0.30 |
| NITE 800 | 90年代の夜とフラッシュ。黒がつぶれる、強いコントラスト、肌は赤く、影はマゼンタ寄り | 0.045 | 1.7 | 0.42 |
| RAINY 400 | 90年代の雨の日と蛍光灯の部屋。青緑に寄る、色が浅い、黒が浮いたマット、ハイライトは少しクリーム色 | 0.034 | 1.5 | 0.12 |

粒子は感度（ISO）の数字に合わせて、数字が大きいほど強く粗くしています。

## 調整のしかた

1. `make_luts.py` の各関数（`sunday400` など）の数値を変える
   - `rgb * np.array([R, G, B])`：ホワイトバランス。Rを上げると暖かく、Bを上げると青く
   - `curve([...])`：トーンカーブ。`(0, 0.035)` の右の数字を上げると黒が浮いて色あせる。`(1, 0.97)` を下げると白がくすむ
   - `split_tone`：影とハイライトにそれぞれ色を足す
   - `saturate`：彩度。1より大きいと鮮やか
2. `python3 make_luts.py` でLUTを作り直す
3. `python3 preview.py` で比較シートを作り直して確認する

比較シートのテスト画像は合成の図形とカラーチャートなので、肌や空の本当の写り方は分かりません。最終的には、昼の屋外・室内・夜のフラッシュ・人物の4種類くらいの実際の写真に当てて調整するのがおすすめです。Lightroomなどで写真を見ながら色を作り、.cubeとして書き出す方法でも大丈夫です。

## 実装メモ

- `.cube` はアプリのバンドルに入れ、`docs/reference/FilmLook.swift` の `loadCube` で `CIColorCubeWithColorSpace` 用のデータに変換します。色空間はsRGBを指定しています。
- 日付の書体は、今はシステムの等幅数字です。7セグメント風の書体を同梱するとより当時らしくなります（ライセンスを確認してください）。
- `CIVignette` の効き方は画像の大きさで変わるので、実機で見ながら `radius` と `intensity` を調整してください。
- NITE 800 はフラッシュ前提の色味なので、フラッシュなしで暗い場所を撮るとほぼ真っ黒になります。それも味ですが、気になるならカーブの黒を少し持ち上げてください。
