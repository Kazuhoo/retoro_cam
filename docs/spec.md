# retoro_cam 仕様書

使い捨てカメラを再現したiOSカメラアプリ。撮った写真はその場では見られず、24枚撮り切って現像に出すと、3日後に封筒に入って届く。届いた写真は1枚ずつ見て、アプリ内のアルバムに残すか捨てるかを決める。

この文書がアプリの正（せい）です。ここに書かれていないことを実装で決める必要が出たら、勝手に決めずに確認すること。

---

## 1. コンセプトと守ること

- **撮る → 待つ → 受け取る → 選んで残す**。撮った直後に写真を見せる機能は作らない。
- 70〜90年代の使い捨てカメラの手触り（巻き上げ、カウンター、フラッシュのスイッチ、封筒、安いポケットアルバム）を大事にする。
- 不便さには意味があるものだけを残す（見られない・待つ・1本を撮り切る）。見づらい・操作しにくいといった、意味のない不便は作らない。
- 機能を増やさない。迷ったら削る。

| 項目 | 内容 |

| 端末 | iPhone のみ |

| UI | SwiftUI（カメラのプレビューなど必要な部分だけ UIKit をラップ） |
| カメラ | AVFoundation |
| 画像処理 | Core Image（`docs/reference/FilmLook.swift` がたたき台） |
| データ | SwiftData |
| 課金 | StoreKit 2 |

| 通知 | UserNotifications（ローカル通知のみ） |
| 写真の保存 | Photos（追加のみの許可 `NSPhotoLibraryAddUsageDescription`） |

| サーバー | なし。すべて端末内で完結する |

### 画面のつながり

```
初回起動 → オンボーディング → （カメラの許可）→ カメラを選ぶ → 横にして構える → 撮影画面
2回目以降の起動 → ホーム（カメラ）

ホーム
 ├ [カメラ] 撮る → 横にして構える →（本体を横にする）→ 撮影画面
 ├ [カメラ] 現像に出す（残り0枚のとき）→ 現像に出す → カメラを選ぶ
 ├ [カメラ] 新しいカメラを開ける（使用中のカメラがないとき）→ カメラを選ぶ
 ├ [封筒] 開ける → 封筒を開けて仕分ける → アルバム／ホーム
 ├ [アルバム] ひらく → アルバム
 ├ カメラを見る → カメラを見る（撮影の途中）→ カメラを買う
 └ 設定アイコン → 設定

撮影画面
 ├ ホームアイコン → ホーム（縦に戻る）
 ├ 設定アイコン → 設定（縦）
 └ 24枚撮り切る → 「現像」ボタン → 現像に出す（縦）

カメラを選ぶ → 有料カメラの「詳しく見る」→ カメラを買う → 「このカメラで撮る」→ 横にして構える
```

### 画面の向き

- Info.plist の対応する向きは Portrait と Landscape Left（音量ボタン側が上）。
- 撮影画面に入るときは Landscape Left だけ、出るときは Portrait だけを許し、`UIWindowScene.requestGeometryUpdate(.iOS(interfaceOrientations:))` と `setNeedsUpdateOfSupportedInterfaceOrientations()` で回す（`AppDelegate` の `supportedInterfaceOrientationsFor` は、`@Observable` の向きの設定を返す）。
- 撮影画面にいる間は、逆さの横持ちや縦持ちでも画面は回さない。縦に持って撮った写真は縦長で保存する（「14. 写真」）。
- 縦向きの画面では、本体を横にしても画面は回さない。

## 5. ホーム

上から：

1. **ヘッダー**：右に「カメラを見る」（ボタン）と設定アイコン。左は空けておく（アプリ名が決まったら検討）。
2. **大きく表示する部分**（画面の大半）：下のアイコンで選んだものを1つだけ大きく出す。切り替えるたびに、下から弾むように出てくる（0.4秒程度）。
   - **カメラ**（起動時はこれ）：
     - 見出し「使用中のカメラ」、立体のカメラ（幅330pt程度。指でぐりぐり回せる）。
     - カメラ名（そのカメラの書体、大きめ）、「24 EXP ・ 残り 07」（残り枚数は黒い窓）。
     - ボタン「撮る」→ 横にして構える。残りが0枚なら「現像に出す」→ 現像に出す。
     - 使用中のカメラがないとき：カメラのかわりに「カメラがありません」と「新しいカメラを開ける」→ カメラを選ぶ。
   - **封筒**：
     - 見出し「届いた封筒」と「新着 ◯」。
     - 届いたロールの封筒を大きく重ねて表示（2通以上なら後ろにもう1通が傾いて見える）。「◯◯ の24枚が届きました」とボタン「開ける」→ いちばん古い未仕分けのロールの「封筒を開けて仕分ける」。途中まで仕分けたロールは、続きから始める。
     - 届いていないとき：点線の枠に「まだ届いていません」。
     - 下に**現像中**のロール（カメラ名・「あと18時間」のような残り時間・進み具合のバー）。なければ出さない。
   - **アルバム**：見出し「アルバム」、少し傾けたポケットアルバムの表紙（大きく）、「52 枚の写真」、ボタン「ひらく」→ アルバム。
3. **下のアイコン**（3つ並び）：「カメラ」「封筒」「アルバム」。選択中はオレンジ（アイコンの後ろに暗いオレンジの丸）。未仕分けの封筒があれば、封筒のアイコンに小さなオレンジの点。
4. **広告**（下端）。

- アイコンはそれぞれ VoiceOver でボタンとして読み、選択中であることを伝える。

## 6. 横にして構える

- ホームの「撮る」（またはカメラを開けた直後）に出す。画面は縦のまま。
- スマホの絵が縦から**右へ（時計回りに）**倒れて横になるアニメーションをくり返す。左側面の音量ボタンが上に来る向き（撮影画面と同じ Landscape Left）。文言：「横にして、構えて」「本体を横に倒すと、カメラが起動します。シャッターは上にきた音量ボタンです。」
- **本体が横になったら自動で撮影画面へ進む**。向きは Core Motion の重力の向きで判定する（画面の回転ロックがオンでも `UIDevice.orientation` は変わらないため）。**音量ボタンが上に来る向き（Landscape Left）に倒したときだけ**、その状態が0.3秒ほど続いたら進む。撮影画面は常に Landscape Left で開く。
- 反対（音量ボタンが下）に倒したときは進まず、文言を「反対向きです」「音量ボタンが上に来るように倒してください」に替える。Landscape Right は使わない（Info.plist にも入れない）。
- 下に「ホームに戻る」。
- 「視差効果を減らす」がオンのときはアニメーションを止め、横向きの絵を出す。

## 7. 立体のカメラ

ホーム、現像に出す、カメラを買う（詳細と購入完了）で使う、厚みのあるカメラの絵。

- 箱型のカメラ（正面、背面、上下、左右の6面）。正面にレンズ（少し前に出す）、ファインダー窓、フラッシュ、カメラ名、テーマの色とストライプ。背面にカメラ名と残り枚数の窓。質感は「4. 見た目の共通ルール」。
- 静止時は少し斜め（左右に約-26°、上下に約12°）を向く。
- **指でドラッグすると回る**。左右は何周でも回せる。上下は ±60° まで。
- 指を離すと、いちばん近い正面向きの角度へ、ばねで少し行き過ぎて戻る（0.8秒程度）。
- 実装は SceneKit（`SCNView`、平面を組み合わせた箱に、テーマから作った画像を貼る）を第一候補とする。SceneKit は iOS 26 で非推奨になったが iOS 17〜26 で動作する。別の方法にする場合は実装前に確認すること。
- アクセシビリティ：画像として扱い、ラベルは「カメラ名 のカメラ」。回す操作は飾りなので VoiceOver では不要。

## 8. 撮影画面（横向き）

### レイアウト
- 左：ファインダー（3:2、モックアップでは 507×338pt）。四隅にフレームの印、周辺を暗く。
- 右上：残り枚数の窓（小）＋ 巻き上げダイヤル（横長）。その下に「巻き上げ　撮ったら、ダイヤルを右へなぞる」。
- 右中：状態表示（「撮影できます」／「ダイヤルを右になぞって巻き上げ」／撮り切ったら「現像」ボタン）。
- 右下：フラッシュのスイッチ（上に説明文）、**ホームアイコン**、設定アイコン。未仕分けの封筒があるときは、ホームアイコンに小さな点をつける（テーマの dot の色）。
- 上端：左にカメラ名（そのカメラの書体）と「・ 24EXP」、右に「▲ シャッター　音量ボタンを押す」。
- 下端：カメラのテーマのストライプと帯。
- 画面にシャッターボタンは置かない。
- DEBUG ビルドでは [ROLL] [TIME] のデバッグ用ボタンを出せる（「18. 設定」のデバッグ欄）。

### 質感（本物のカメラを持っている感じ）
- **本体**：テーマの地の色に、プラスチックの細かいざらつきと成形のムラ。左上から光が当たり、下へ少し暗くなる。上のふちに明るい線（面取り）。
- **ネジ**：本体の3か所（左下・右上・右下の角の近く）にマイナスネジ。
- **下の帯**：印刷したシールのかすれ。
- **ファインダー**：黒いゴムのふち（太め）で囲み、ガラスに細かいほこりと上ふちの反射。
- **残り枚数の窓**：ガラスの映り込み。本体にはめ込んだ段差（周りに暗い溝と下側のハイライト）。
- **巻き上げダイヤル**：円筒の陰影で丸み。ギザギザに金属の角の光と細かい傷（ダイヤルと一緒に流れる）。本体に埋め込んだ段差。
- **フラッシュのスイッチ**：ざらつきのある樹脂のつまみ。溝は本体にはめ込んだ段差。
- **ホーム・設定のボタン**：少し盛り上がった丸いボタン。
- 質感は6つのテーマすべてで、地の色が濁らない強さにする。

### ファインダー
- **フィルムの色をかけない素の映像**を出す。どう写るかは現像まで分からない。
- 日付もファインダーには出さない。

### シャッター
- 音量ボタン（上下どちらも）とカメラコントロール（対応機種）で撮る。`AVCaptureEventInteraction` を使う。
- `AVCaptureSession` が動いている間だけ有効。
- **シャッター音は iOS 標準の音を使い、アプリからは消さない**（設定で消せない）。地域によっては消音モードで鳴らないことがある。
- 巻き上げが済んでいないときは何も起きない（軽いハプティクスで知らせる）。
- 撮影時の合図：フラッシュなしならファインダーが一瞬（0.08秒くらい）暗くなる。フラッシュありなら白く光る。

### 巻き上げダイヤル
- 横長のホイール。**右になぞると巻き上がる**。左になぞっても戻らない。
- なぞった量に合わせて溝が流れ、**残り枚数の窓の数字が次の数字へじわっと回る**（数字の円盤が回るイメージ）。
- 回り切ったら巻き上げ完了。それ以上なぞると軽く跳ね返る。
- 一定量ごとにカチカチとハプティクス、巻き切りで少し強め。巻き上げ音あり（設定で消せる）。
- キーボードの右矢印でも巻ける（アクセシビリティ）。

### 残り枚数
- 新しいカメラは「24」で撮影可能な状態から始まる。
- 撮る → 数字はそのまま、巻き上げ待ち → 巻くと 24→23 へ回る → 撮影可能。
- 最後の1枚を撮ると「00」になり、巻き上げ不可。「現像」ボタンが出る。

### フラッシュ
- 縦のスライドスイッチ。つまみに丸い突起が4つ（2×2）。**下から上に上げるとON**。
- ONにすると横のランプがすぐ点く（充電時間なし）。
- **1枚撮るたびにスイッチは下に戻る**。続けて使うなら上げ直す。
- 説明文：「フラッシュ／上げるとON／1枚ごとに上げ直す」。
- カメラの機能はフラッシュだけ（インカメラ、ズーム、露出補正などは作らない）。

## 10. カメラを選ぶ（カードの束）

- 縦長のカード（モックアップでは 226×300pt）が、手前の1枚を中心に扇状に重なる。
- カードの表：番号（No.01〜）、カメラの絵、カメラ名（そのカメラの書体）、ISO、ひとことの説明、「無料」／「購入済み」／価格のバッジ、光の反射。
- **左右にドラッグ・フリックで手前のカードが替わる**。指についてきて、離すとばねで落ち着く。左右の矢印ボタン、下の点、キーボードの左右キーでも替えられる。
- **手前のカードをタップすると裏返り（左右に180°回る）、作例が1枚、カード全体に表示される**。左上に「作例」、下にカメラ名と日付の焼き込み。もう一度タップで表に戻る。奥のカードをタップすると、そのカードが手前に来る。

## 11. ロールと現像のルール

- どのカメラも **24枚撮り**。
- **持てるカメラは1台だけ**。撮り切るまで別のカメラに替えられない。
- 撮り切ったら「現像に出す」。途中で現像に出すことはできない。
- 現像には **3日**（72時間）かかる。現像に出した時刻＋72時間で届く。
- 現像に出したら、すぐ次のカメラを開けられる（待っている間も撮れる）。現像中のロールは何本あってもよい。
- 届いたらローカル通知を出す（現像に出した時点で72時間後の通知を予約する）。
- 通知の文言（案）：「写真が届きました。SUNDAY 400 の24枚です。」通知をタップしたら、そのロールの「封筒を開けて仕分ける」を開く。
- アプリを開いている間は通知のバナーを出さない。届いたことは、ホームの封筒のアイコンと撮影画面のホームアイコンの点で知らせる。

### 現像に出す画面
- 確認：立体のカメラ（残り枚数「00」）、カメラ名、「24枚、撮り切りました。」「現像に出しますか？」、「写真は11月11日（水）ごろ、封筒に入って届きます。」「同じカメラは、新しく開ければまた使えます。」、ボタン「あとで」（→ ホーム）「現像に出す」。
- 出した直後：カメラが右へ滑って消え、**「現像 お預かり票」**の紙が落ちてくる（少し傾いている）。
  - 票：上にオレンジの帯「現像 お預かり票」とミシン目、「お届け予定」と日付（例「11/11」、VT323 の大きな字）、手書き風の「24枚撮り ・ 1本」、右に赤い丸の「受付」のはんこ。紙の質感。
  - 文言「現像に出しました」「3日後、◯月◯日ごろに届きます。」「届いたらお知らせします。」「待っている間も、新しいカメラで撮れます。」ボタン「新しいカメラを開ける」（→ カメラを選ぶ）。

### 封筒
- 横長の封筒。上に**長方形のふた**（三角ではない）。シール（封）は付けない。
- 色は「9. カメラ」の封筒の表。下にストライプと帯、右下にラベル（カメラ名・24EXP・撮影期間）。質感は「4. 見た目の共通ルール」。

## 12. 封筒を開けて仕分ける

ヘッダー：左に「ホーム」、中央に撮影期間（例「10/12〜10/19」）、右に何枚目か（例「3/24」、開ける前は空）。下端に広告。

### 封筒（開ける前）
- 「写真が届きました」、大きな封筒。
- **ふたを上へなぞるとめくれ**（中の写真が少し見える）、6割以上で指を離すと開く。途中なら閉じる。
- 「ふたを上へめくって開ける」と上向きの矢印、「写真は1枚ずつ、アルバムに残すか捨てるかを決めます。」「ボタンで開ける」。

### 仕分け
- 写真を画面の幅いっぱいに大きく1枚ずつ表示（白いふち付き、3:2）。下に次の写真が少しずれて重なって見える。縦長の写真は、ふち付きの縦長で表示する。
- **右へスワイプでアルバムに残す、左へスワイプで捨てる**。指についてきて傾き、右に動かすと緑の「アルバムへ」、左に動かすと赤の「すてる」のスタンプが濃くなる。90pt を超えて離すと決定、写真は画面の外へ飛んでいく。足りなければ戻る。
- 下にボタン：「捨てる」（左）、「ひとつ戻す」（中央、1枚目では出さない）、「残す」（右）。
- 下に「右へスワイプでアルバムに残す／左へスワイプで捨てる」。
- 仕分けの途中でアプリを閉じても、どこまで決めたかは残る。次に開けると続きから。

### 仕分けが終わった
- 「仕分けが終わりました」、「アルバムに ◯枚」「捨てた ◯枚」。
- 「アルバムに残した写真は、写真アプリにも保存されます。」
- ボタン「アルバムを見る」「ホームへ」、小さく「最後の1枚をやり直す」。
- **この画面を離れたとき（「アルバムを見る」「ホームへ」「ホーム」）に確定する**：
  - 残した写真を、まとめて写真アプリへ保存する（初回はここで写真の追加の許可を求める）。保存できたら `Roll.savedToPhotosAt` を記録する。
  - 捨てた写真は、アプリ内のファイルごと削除する（元に戻せない）。
- 確定前にアプリが終了した場合は、次にこのロールを開いたとき「仕分けが終わった」画面から再開する。

## 13. アルバム

- 安い青いプラスチックのポケットアルバム。左端にリング。**1ページずつ**表示し、1ページに **ポケット3つ**（縦に並ぶ）。質感は「4. 見た目の共通ルール」。

- ヘッダー：左に「ホーム」、中央に「アルバム」。下端に広告。

## 14. 写真

- **3:2**、**1536×1024px**（JPEG、品質0.88目安）。当時の写真屋さんのCD書き込み相当。
- 撮影直後に加工してアプリ内（Documents 配下、iCloudバックアップ対象）に保存。仕分けで残すと決めるまで、写真アプリには保存しない。
- 加工の順番：3:2に切り抜き → 縮小 → LUT → 粒子 → 周辺減光 → 光漏れ（ONのとき）→ 日付（ONのとき）。
- **日付と光漏れは、撮った瞬間の設定で焼き込む**（あとから設定を変えても、撮影済みの写真は変わらない）。
- 日付の形式：`'26 11 08`（年2桁、月、日）。オレンジ、右下、少しにじむ。
- 光漏れは画像の左右どちらかの端から入るオレンジ〜赤の光。位置と強さはランダム。
- 縦に持って撮ったら、写真は縦長で保存する（`AVCaptureDevice.RotationCoordinator` の `videoRotationAngleForHorizonLevelCapture`）。
- 縦長の写真の加工も、本物の使い捨てカメラと同じくフィルムの向き（横）で行う。シャッターである音量ボタンの側を上にした横向きで見たときに、日付が右下で正しく読める形に焼き込む。縦で見ると日付は**右上**で、**下から上へ**年・月・日の順に並ぶ（縦持ちの向きによらず固定）。
- 写真アプリに保存するとき、作成日時は**撮影日時**にする（`PHAssetCreationRequest` の `creationDate`）。
- 色味（LUT）と粒子・周辺減光の値：`tools/looks/README.md` と `Resources/LUTs/`。

## 16. 広告（AdMob）

- アンカー型アダプティブバナーを画面下端に表示する。高さはSDKが返す値を使う。セーフエリアの内側に置く。
- 表示する画面：ホーム、カメラを選ぶ、カメラを見る、封筒を開けて仕分ける、アルバム。
- 表示しない画面：横にして構える、撮影画面、設定、カメラを買う、現像に出す、オンボーディング。
- 購入者には表示しない。
- 同意の流れ：
  - 初回起動のセッションでは広告を読み込まない。
  - 2回目以降の起動で、かつオンボーディングの完了後に、**UMP（必要な地域だけフォームが出る）→ ATT** の順で出し、終わってから広告を読み込む。
  - 購入者には UMP も ATT も出さず、SDK も開始しない。購入がなくなった場合は、次の起動で同意の流れが出る。
- 広告を出す画面で、広告ユニットを1つ共用する。
- 購入者と初回起動のセッションでは広告枠ごとなくす。広告を出すセッションでは、読み込み前や失敗時も SDK の高さ分を空けておく。
- ATT の説明文：「あなたの興味に合わせた広告を表示するために使います。」
- `SKAdNetworkItems` は Google の ID のみ。全一覧はストア申請の準備で入れる。
- 広告ユニットIDなどはリポジトリに直接書かず、`.xcconfig`（gitignore対象）から読む。開発中はテスト用IDを使う。

## 19. オンボーディング（縦、4ページ）

1. ようこそ：「撮って、待って、受け取るカメラ」／「撮った写真は、その場では見られません。使い捨てカメラのように、現像されるまでのお楽しみです。」／撮る→待つ→受け取るのアイコン
2. シャッター：「横に持って、音量ボタンで撮影」／「画面にシャッターボタンはありません。本体の上にきた音量ボタンを押すと撮れます。」
3. 巻き上げ：「1枚撮ったら、ダイヤルを巻き上げる」／「右上のダイヤルを右になぞると、残り枚数が回ります。数字が回り切ると、次の1枚が撮れます。」
4. 現像：「24枚撮り切ったら、カメラごと現像に出す」／「現像には3日かかります。写真は封筒に入って届きます。1枚ずつ見て、アルバムに残すか決めましょう。」
- 絵が上、文言が下。「スキップ」「戻る」「次へ」、最後は「最初のカメラを開ける」（→ カメラの許可 → カメラを選ぶ）。「スキップ」は最後のページへ飛ぶ（カメラの許可は「最初のカメラを開ける」で求める）。
- 設定の「使い方を見る」からいつでも見られる。このときの最後のボタンは「閉じる」で設定へ戻り、許可の確認は出さない。

## 20. データモデル（案）

```swift
// SwiftData
@Model final class Roll {
    var id: UUID
    var cameraID: String          // "sunshine" など
    var createdAt: Date           // カメラを開けた日時
    var state: RollState          // .shooting / .developing / .delivered / .sorting / .sorted
    var sentAt: Date?             // 現像に出した日時
    var deliverAt: Date?          // sentAt + 72時間
    var openedAt: Date?           // 封筒を開けた日時
    var sortedAt: Date?           // 仕分けを確定した日時
    var savedToPhotosAt: Date?    // 残した写真を写真アプリへ保存できた日時
    @Relationship(deleteRule: .cascade) var shots: [Shot]
}

@Model final class Shot {
    var id: UUID
    var index: Int                // 1〜24
    var takenAt: Date
    var fileName: String          // Documents/Rolls/<rollID>/<index>.jpg
    var isPortrait: Bool
    var decision: Decision?       // nil=未定 / .keep / .discard
}
```

- 撮影中の状態（巻き上げ済みか、フラッシュ）は保存しなくてよい。起動時は「巻き上げ済み」で始める。
- 現在時刻は `Clock` プロトコル経由で取得し、デバッグメニューで時間を進められるようにする（3日待たずに確認するため）。
- 届いたかどうかは `deliverAt <= now` で判定する（通知はおまけ。通知が来なくてもホームに届いている）。
- 仕分けの確定で `decision == .discard` の Shot はファイルごと削除する。
- アルバム ＝ `state == .sorted` のロールの `decision == .keep` の Shot を `takenAt` 順に並べたもの。「アルバムから抜く」は Shot とファイルを削除する。
- 「ひとつ戻す」は、いちばん最後に決めた Shot の `decision` を nil に戻す。
- 既存のデータ（旧版の `.opened` のロール）は、全部の Shot を `.keep` にして `.sorted` として移行する（すでに写真アプリに保存済みなので `savedToPhotosAt` は保つ）。

## 21. 効果音・ハプティクス

- シャッター音（iOS 標準）、巻き上げのラチェット音、巻き切りのカチッ、フラッシュのスイッチ音、封筒のふた・袋を破る音、写真を仕分ける音（紙がすべる音）、アルバムのページをめくる音。
- シャッター音以外は合成した素材（`tools/sounds`）を `Resources/Sounds` に置く。同じファイル名の録音素材に置き換えれば差し替えられる。消音モードに従い、音楽は止めない。
- 巻き上げ：一定量ごとに `UIImpactFeedbackGenerator(.rigid)` 弱め、巻き切りで強め。
- フラッシュのスイッチ：切り替えたときに `UIImpactFeedbackGenerator(.rigid)` 弱め。
- 巻き上げ前にシャッターを押したとき：弱め。
- 袋を破り切ったとき、封筒のふたが開いたとき：強め。
- 仕分け：決定のしきい値を超えた瞬間に軽く。

### アクセシビリティ

- VoiceOver：アイコンのボタン、ダイヤル（上下スワイプで巻ける）、フラッシュのスイッチ、残り枚数、ホームの下のアイコン、カードの束を読み上げる。
- 「視差効果を減らす」がオンのときは繰り返しのアニメーションを止める。
- Dynamic Type には今回は対応しない（固定レイアウトのため）。
