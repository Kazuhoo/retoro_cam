# モックアップ

各画面のモックアップです。`.dc.html` はデザインツール用の形式ですが、中身は普通のHTMLとCSSなので、レイアウト・色・文言をそのまま読み取れます。ブラウザで直接開いても表示はされません（専用の実行環境が必要なため）。

- 元のキャンバス（操作できる版）：https://claude.ai/artifact/5RrYCqgu4PSLytfhj9aw9y （所有者のみ閲覧可）
- 画面とファイルの対応は `docs/spec.md` の「画面一覧」を参照
- 画面の大きさは、撮影画面（`Main`）だけ 844×390pt（横向き）、ほかは 390×844pt（縦向き）
- `{{...}}` はモックアップ内の変数。値は各ファイル末尾の `<script>` にある

モックアップと spec.md が食い違うときは spec.md を優先します。
